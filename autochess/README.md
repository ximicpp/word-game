# 词宝小队（原型）

独立的单词自走棋小游戏，和单词星系分开。每个英文单词是一只“词宝”：答对题才能请到它，把有关系的词宝排在一起触发组合，然后两队自动扔星星泡泡比赛。面向已学过 KET/PET 词汇的小学生，画面和用词都按小学生来定（没有打打杀杀的字眼）。

- 在线游玩（合并后）：https://ximicpp.github.io/word-game/autochess/
- 单文件 `index.html`，无依赖；进度存在本机浏览器（key `word-buddies-v1`）。
- 设计文档：https://claude.ai/artifact/AdKGnvdy8xy8GKEBKjNT2Z

## 玩法

| 部分 | 规则 |
|---|---|
| 一局 | 8 回合，10 颗爱心；输一场少 1 颗（对面剩 3 只以上少 2 颗），下一场对手会弱一点；撑过 8 回合就通关，按赢的场数给 1–3 星 |
| 词宝 | 词性决定类型：名词 🐻 盾盾宝（能量多）、动词 🐰 冲冲宝（力气大）、形容词 🦄 魔法宝（顺带砸到旁边）、副词 🐦 闪闪宝（最快，专找后排）。A2 词 1 词币，B1/B2 词 2 词币且更强 |
| 请词宝 = 答题 | 第 1 次请：选中文意思；第 2 次：例句选词填空（升 2 星）；第 3 次：字母块拼写（升 3 星，戴皇冠 👑） |
| 答错 | 不扣词币，显示答案和例句，这张卡本回合休息；同一回合错满 3 题，词宝老师 🦉 把这 3 个词再讲一遍 |
| 组合 | 同主题“同班同学”2/4/6 只：开场护盾泡泡；同词根“一家人”2/3/4 只：力气变大；反义“对对碰”两只挨着：开场 3 秒放烟花 |
| 小屋提示 | 能和草地上的词宝凑组合的词卡带 🤝，能升星的带“升2★/升3★”；有能升星的词宝时每次至少出一张升星卡 |
| 关系题 | 每个组合第一次出现时问“这两个词是什么关系”，答对本局加强一档并送 1 词币 |
| 魔法贴纸 | 赢一场有机会得到前后缀贴纸（un- -er -or -ful -ly -y -ness）。贴到对应词宝上并选对拼法（happy+ly=happily、sun+y=sunny、swim+er=swimmer），它就变成新词，类型跟着词性变；选错贴纸留着下次再试 |
| 词币 | 每回合 +5；存钱罐每存 5 个多给 1 个（最多 2）；赢一场 +1；连对 3 题 +1；换一批 1 个；扩建草地（多放 1 只）3+等级 个；输一场也有 1 个加油奖 |
| 对手 | 按回合变强的练习队；你赢过的队伍会存下来，以后有时会碰到“你以前的队伍” |
| 复习 | 小屋抽卡时更常出现到期该复习的词和答错过的词；首页有错词本和皇冠词 |

## 词池

`node tools/build-autochess.js` 从 `words/*.txt` 取级别、中文和例句，加上脚本里手工标注的词性、主题、词根家族和反义对，写进 `index.html` 的 `/*DATA*/` 区。目前 8 个主题 140 词、11 个词根家族、23 组反义对；每局随机用其中 5 个主题。

## 试玩时看两件事

孩子会不会为了凑组合主动去请某个词、主动挪位置让反义词挨着；玩完能不能说出几组“一家人”和“对对碰”。
