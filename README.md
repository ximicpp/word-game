# 词网点灯 Word Net

一个帮中小学生（已过 KET / PET）分清易混单词的网页小游戏。单词按读音、字形、近义、反义、同词根、搭配、同主题、上下位 8 种关系连成一张网，从起点开始，每个单词 3 道选择题全对即可点亮，点亮后相邻单词解锁。

- 在线游玩：https://ximicpp.github.io/word-game/
- 纯静态网页，无需登录，进度保存在本机浏览器。
- 换词库只需修改 `data.js`（单词表 + 连线表 + 星座表）。

## 玩法

- **星级**：一次全对得 3 颗星；答错只需重做那一题（换一道同类题），每错一次少一颗星，最少 1 颗。
- **连击**：连续答对累计连击，每 5 连击有流星。
- **星光变暗**：点亮后 1、3、7、14、30 天依次需要“擦亮”（答 1 题）。擦亮时一次答对还能加一颗星。网址加 `?days=3` 可以模拟 3 天后。
- **星座**：15 个星座互不重叠，覆盖全部单词。星座里的词全部点亮就连成星座，可以收起成一颗“星座大星”。收起只改变显示：内部连线藏起来，连到外面的线从大星出发，同一对之间的多条线合成一束并标出数量；解锁和出题仍按原始连线计算。
