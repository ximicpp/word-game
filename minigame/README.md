# 单词星系 · 微信小游戏版

这个目录是单词星系的微信小游戏工程。微信开发者工具里用「导入项目」选这个目录即可。

## 为什么是小游戏，不是小程序

- 小游戏没有网页的 DOM，所以界面用一块 Canvas 重新画；玩法、词库、存档规则和网页版一致（`js/core.js` 照搬网页版 `index.html` 里的规则）。
- 个人主体可以上线**不带内购**的小游戏，不需要版号。
- 普通小程序里放游戏玩法，审核通常会要求改成小游戏；个人主体能选的教育类目也很少。

## 文件

| 文件 | 作用 |
| --- | --- |
| `game.js` / `game.json` | 小游戏入口和配置（竖屏） |
| `project.config.json` | 开发者工具项目配置，`appid` 在这里 |
| `js/core.js` | 规则：词库筛选、点亮解锁、推荐、星级与复习、出题 |
| `js/main.js` | 界面：一整张星空（拖动、双指缩放、点最近的星）、热力场、点亮动画、面板、答题、我的星图 |
| `js/ui.js` | Canvas 绘图和中英文混排换行 |
| `js/platform.js` | 微信接口封装：画布、安全区、胶囊按钮、存储、触摸、音效、分享 |
| `js/data.js` | 词库，由 `node tools/build-minigame.js` 从根目录 `data.js` 生成，**不要手改** |
| `dev/` | 浏览器预览和图标，不会打进小游戏包 |
| `test/` | 规则自测，不会打进小游戏包 |

## 改词库以后

`node tools/build.js` 会顺带更新 `minigame/js/data.js`。只改了 `data.js` 时，运行 `node tools/build-minigame.js`。CI 会检查两者是否一致，并检查包大小（主包上限 4 MB，现在约 2 MB）。

## 在浏览器里预览

```
python3 -m http.server 8000
```

在仓库根目录运行，然后打开 http://localhost:8000/minigame/dev/preview.html 。参数：`?w=375&h=667` 换手机尺寸，`?days=3` 模拟 3 天后，`?reset=1` 清空存档。预览只模拟了用到的几个 `wx` 接口，最终以开发者工具和真机为准。

## 自测

```
node minigame/test/core.test.js
```

4 个词库里每个词的每种题型都出一遍，检查选项不重复、包含答案；再模拟一路点亮和 30 天后擦亮。

## 上线步骤（需要账号主人操作）

1. **确认账号类型**：在 [mp.weixin.qq.com](https://mp.weixin.qq.com) 登录，「设置 → 基本设置 → 服务类目」选「游戏」下的休闲益智类。选了游戏类目才是小游戏；已经选了别的类目的账号可能不能改，需要另注册一个小游戏账号。
2. **AppID**：「开发管理 → 开发设置」里的 AppID 已填进 `project.config.json` 的 `appid`（wx3e0ec4d809a28f68）。换账号时改这里。
3. **名称、头像、简介**：名称建议“单词星系”（要先查重）；头像可以用 `dev/icon-512.png`。
4. **备案**：后台「小程序备案」，个人主体要身份证和人脸核验，一般 1–3 周。没备案不能上线。
5. **游戏资质**：免费、无内购的小游戏不需要版号，但要上传《计算机软件著作权登记证书》（或电子版权认证）和《游戏自审自查报告》（后台有模板）。软著办理一般要 1 个月左右。
6. **用户隐私保护指引**：本游戏不收集任何个人信息，进度只存在本机（`wx.setStorageSync`），没有调用定位、相册、用户信息等接口，按“未收集”填写即可。
7. **上传与提审**：开发者工具里先「预览」用手机扫码试玩，没问题后「上传」，到后台「版本管理」把开发版提交审核，审核通过后发布。

## 版本

和网页版 v1.13 同步：一整张星空（不分星系，想学哪个词就点哪个）、星等（重要程度决定 3–5 题和亮度）、热力场底图、点亮动画、补字母题、观星者等级和考纲里程碑、连续天数和守护星、每周回顾、恒星。点亮的词之间平时只画骨架连线。没有虚线。

v1.14 起针对手机重新排版：顶栏一行，下方是可以拉动的抽屉（露一条 / 一半 / 大部分三档），星图铺满屏幕；打开时放大到“下一颗”附近并标出周围词名；“全览”看整片星空；星挤在一起时弹出小列表选；星尘和音效在等级页。

v1.18 起：新玩家有开场封面，头 3 颗星少出题；顶栏写明今日进度；完成今日目标、升级、里程碑时可以分享自己的星空卡片（`platform.js` 的 `shareNow`，图片用离屏画布现画）。

## 和网页版的差别

- 词库切换用微信的操作菜单，重新开始用系统确认框。
- 没有键盘快捷键；按钮按下时有高亮。
- 星图分两层：热力场、亮线、星点画进离屏画布，拖动时平移贴图，停下来再重画；选中、动画和名字每帧画。空闲时降到约 15 帧省电。
- 名字只给选中的词和它最重要的 14 个相关词（手机上没有悬停）。
- 点亮时手机会轻微震动；右上角菜单可以分享给好友和朋友圈。
