# 单词星系 Word Galaxy

一个帮中小学生巩固 KET / PET / FCE 词汇的网页小游戏。3716 个单词按读音、字形、近义、反义、同词根、搭配、同主题、上下位 8 种关系连成网（约 1.6 万条连线，每个词在自己的主题里至少连着 4 个词），全部放在一整张星空里。以浏览为主：在星空里随意点开单词，看意思、例句和它的相关词；想学会哪个，就做题把它点亮。

- 在线游玩：https://ximicpp.github.io/word-game/
- 纯静态网页，无需登录，进度保存在本机浏览器。
- 词表按剑桥 A2 Key（KET，1194 词）、B1 Preliminary（PET，1041 词）和 B2 First（FCE，1481 词）的范围整理；释义、音标、例句和关系为本项目编写，例句均为原创。

## 玩法

- **词库**：左上角选择 KET、PET、KET+PET 或 KET+PET+FCE。同一个词在不同词库里只要点亮一次。
- **浏览与点亮**：所有单词一开始就能看，点开任何词都显示意思、例句、相关单词和关系。想学哪个就点“做题点亮”，右侧也会推荐下一颗（优先挨着已点亮的词和重要的词）。题目从 7 种题型里随机抽：看英文选中文、看中文选英文、关系、填空、拼写（选对的拼写）、补字母（挖掉两个易错字母）、看音标选词（一道考意思，能拼的词还一定有一道考拼写）。
- **星等（难度 = 亮度）**：和别的词有关系越多（不算同主题），这颗星越重要：三等星 3 题、二等星 4 题、一等星 5 题。星等越高，地图上越大，点亮后越亮，星尘也越多。
- **亮与暗**：没点亮的星是实心的小暗点（星等越高越大），没点亮的边平时不画；一条边两端的词都点亮了，它才变成亮的实线。只有一端点亮的边，会从亮的那一端透出一小段光；挨着亮星的暗星带一点暖色。选中一个词时，它没点亮的连线用细一点、淡一点的实线标出，没学的相关词是空心圈。全部用实线，不用虚线。
- **热力场底图**：每颗点亮的星都是一个热源（星等、星级越高越热，变暗待擦亮的只剩余温，恒星更热），所有热源叠加成一个温度场画在星空最底层，从深紫、玫红、橙到暖金，带淡淡的等温线。刚开始是一个个暖点，学得多了会连成一块块“暖大陆”，没学的地方是冷的暗区。点亮动画放完后，新的热量再慢慢晕开。
- **点亮动画**：答题时地图上这颗星的外圈按进度一段段亮起；答完后镜头对准它，星星从暗处燃起，冲击波扩散，再有光沿着连线一条条流向已经点亮的邻居，邻居闪一下回应，最后显示“+N 条星光”。答对自动进入下一题；答错只重做那一题，并换一种题型。
- **星级与连击**：一次全对 3 颗星，每错一次少一颗（最少 1 颗）。连续答对累计连击，每 5 连击有流星。
- **一整张星空**：不再分星系，所有单词和连线都在同一张图上，有关系的主题会自然靠在一起。平时地图上不显示单词名字，鼠标移上去才显示；选中一个词时，它的连线和相关词会高亮，并给最重要的 14 个相关词标上名字。
- **地图图例与单词本**：地图左下角显示已学会、未学会各有多少，点“已学会”只看学会的词（下面写着中文），点“未学会”只看还没学的词。“单词本”按星座分组列出所有词，点一个词跳到地图上。
- **星座**：单词按关系分成若干 3–6 个词的星座，全部点亮后自动收起成一颗大星，点它可以展开。收起只改变显示，出题仍按原始连线计算。
- **星光变暗**：点亮后 1、3、7、14、30 天依次需要“擦亮”（答 1 题），顶部会出现“待擦亮”按钮，点一下直接开始。网址加 `?days=3` 可以模拟 3 天后。
- **恒星**：一个词通过 1、3、7、14 天的 4 轮擦亮后变成金色恒星，30 天才需要擦亮一次；擦亮答错就退回普通星。
- **每周回顾**：每周第一次打开时，显示上周新点亮、擦亮、新恒星和升级的数量，以及这周离下一级还差多少。
- **星尘与提示卡**：点亮得星尘（难度×10 + 星级×5，连成星座再 +30）。答题时可花 30 星尘去掉两个错误选项。
- **观星者等级**：按累计点亮的词数升级（10、25、45、70、100……颗），顶栏显示等级和到下一级的进度；每 4 级换一个称号。升级时结果卡回顾这一级点亮了哪些词。
- **考纲里程碑**：KET、PET、FCE 各自点亮 25%、50%、75%、100% 时弹出纪念卡，点顶栏的等级可以看到各级进度和达成日期。
- **今日目标**：每天点亮或擦亮 10 颗星，完成得 50 星尘。
- **连续天数与守护星**：每天点亮或擦亮 1 颗就算连续，顶栏目标圈旁显示天数；连续 3、7、14、30、50、100、200、365 天各有一张纪念卡。在“我的星图”里可以用 100 星尘换守护星（最多存 2 颗），哪天没来会自动用掉 1 颗，连续天数不断；断了只是从 1 重新开始，不扣其他东西。
- **幸运星**：每天在没学会的词里挑一颗（地图上带 ✦），点亮它星尘翻倍。
- **其他**：键盘 1–4 选答案、回车继续；顶部可关音效；新手提示每条只出现一次。

## 词库

词库源文件在 `words/*.txt`，一行一个词：

```
# 星系名 | id
## 小话题
word|A2|ipa|中文|例句（必须包含这个词）|syn:xx;ant:yy;hyper:zz;sound:zz;coll:短语
```

级别写 A2 / B1 / B2。运行 `node tools/build.js` 生成 `data.js`：自动补充读音相同或押韵、拼写相近、同词根与合成词、中文释义相同、例句里的搭配、同主题的连线，并读入 `words/links.txt` 里手写的反义、近义、上下位和搭配表；读入 `words/links-gal.txt` 里按主题补的关系，并保证每种词库组合下每个词在自己主题里至少有 4 条连线、每个主题内部连通；分出星座，最后把所有单词放进一整张星空做力导向布局。构建会检查例句、重复词和孤立词，有错误时不输出。`node tools/dedupe.js` 可删除重复的词条。

## 单文件离线版

运行 `node tools/build-offline.js`，会生成 `dist/单词星系-离线版.html`。将这个文件发给朋友，下载后用浏览器打开即可游玩，无需网络；离线版使用系统字体。游戏进度保存在各自的浏览器中，浏览器对本地文件存储的处理可能不同。

## 微信小游戏版

`minigame/` 是微信小游戏工程，用 Canvas 重画界面，玩法和网页版一致。微信开发者工具里导入这个目录即可预览和上传。说明、浏览器预览方法和上线步骤见 [minigame/README.md](minigame/README.md)。

## 自动构建与发布

GitHub Actions 在推送分支、提交或更新 Pull Request 时自动构建，也可以在 Actions 页手动运行“构建与发布”。运行完成后，从该次运行的 Artifacts 下载 `word-game-html`、`word-game-android` 或 `word-game-minigame`（微信小游戏工程，解压后用开发者工具导入）。网页文件下载解压后即可离线打开。

推送以 `v` 开头的标签（例如 `v1.0.0`）会在三个构建都成功后创建 GitHub Release，并附上 HTML、APK 和小游戏工程。创建标签和推送由维护者执行；仓库需要启用 Actions 和允许工作流创建 Release。已有同名 Release 时发布步骤会失败，避免覆盖已有文件。

Android 使用 Java 11、Gradle 7.3.3、Android SDK 34 和 Build Tools 34.0.0；本地可在 `android-offline` 目录运行 `gradle assembleDebug`。当前 APK 使用构建机器临时生成的调试密钥签名，适合体验，不保证不同构建可以直接覆盖安装，也不适合应用商店发布。需要稳定升级或正式发布时，应配置并安全保管固定的正式签名密钥。
