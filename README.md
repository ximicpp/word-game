# 单词星系 Word Galaxy

一个帮中小学生巩固 KET / PET / FCE 词汇的网页小游戏。3716 个单词按读音、字形、近义、反义、同词根、搭配、同主题、上下位 8 种关系连成网（近 1 万条连线，平均每个词连着 5 个以上的词），分成 19 个主题星系。答对题目点亮单词，点亮后相邻的词就能挑战，整张网从起点一圈圈亮起来。

- 在线游玩：https://ximicpp.github.io/word-game/
- 纯静态网页，无需登录，进度保存在本机浏览器。
- 词表按剑桥 A2 Key（KET，1194 词）、B1 Preliminary（PET，1041 词）和 B2 First（FCE，1481 词）的范围整理；释义、音标、例句和关系为本项目编写，例句均为原创。

## 玩法

- **词库**：左上角选择 KET、PET、KET+PET 或 KET+PET+FCE。同一个词在不同词库里只要点亮一次。
- **点亮**：打开就能玩，右侧总是给出“下一颗”推荐和开始按钮。每个词从 6 种题型里随机抽 3 道：看英文选中文、看中文选英文、关系、填空、拼写、看音标选词（至少一道考意思）。答对自动进入下一题；答错只重做那一题，并换一种题型。
- **星级与连击**：一次全对 3 颗星，每错一次少一颗（最少 1 颗）。连续答对累计连击，每 5 连击有流星。
- **星系**：19 个主题星系，地图上方切换。每点亮 12 个词开放一个新星系；如果点亮的词和别的星系有连线，那个星系也会提前开放。
- **星座**：每个星系里有若干 3–6 个词的星座，全部点亮后自动收起成一颗大星，点它可以展开。收起只改变显示，解锁和出题仍按原始连线计算。
- **星光变暗**：点亮后 1、3、7、14、30 天依次需要“擦亮”（答 1 题），顶部会出现“待擦亮”按钮，点一下直接开始。网址加 `?days=3` 可以模拟 3 天后。
- **星尘与提示卡**：点亮得星尘（难度×10 + 星级×5，连成星座再 +30）。答题时可花 30 星尘去掉两个错误选项。
- **今日目标**：每天点亮或擦亮 10 颗星，完成得 50 星尘，并记录连续天数。
- **幸运星**：每天在能挑战的词里挑一颗（地图上带 ✦），点亮它星尘翻倍。
- **其他**：键盘 1–4 选答案、回车继续；顶部可关音效；新手提示每条只出现一次。

## 词库

词库源文件在 `words/*.txt`，一行一个词：

```
# 星系名 | id
## 小话题
word|A2|ipa|中文|例句（必须包含这个词）|syn:xx;ant:yy;hyper:zz;sound:zz;coll:短语
```

级别写 A2 / B1 / B2。运行 `node tools/build.js` 生成 `data.js`：自动补充读音相同或押韵、拼写相近、同词根与合成词、中文释义相同、例句里的搭配、同主题的连线，并读入 `words/links.txt` 里手写的反义、近义、上下位和搭配表；保证每种词库组合下每个星系内部都连通，分出星座并算好布局。构建会检查例句、重复词和孤立词，有错误时不输出。`node tools/dedupe.js` 可删除重复的词条。
