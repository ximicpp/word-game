# 词宝小队（原型）

独立的单词自走棋小游戏，和单词星系分开。每个英文单词是一只“词宝”：答对题才能请到它，把有关系的词宝排在一起触发组合，然后两队自动扔星星泡泡比赛。面向已学过 KET/PET 词汇的小学生，画面和用词都按小学生来定（没有打斗和吓人的字眼）。

- 在线游玩（合并后）：https://ximicpp.github.io/word-game/autochess/
- 单文件 `index.html`，无依赖；进度存在本机浏览器（key `word-buddies-v1`）。
- 设计文档：https://claude.ai/artifact/AdKGnvdy8xy8GKEBKjNT2Z

## 玩法

v0.6 按自走棋这类游戏的常见框架补齐了玩法（8 队同场、等级与抽卡概率、利息和连胜连败、技能条、道具、PvE 回合），但角色、名字、道具和数值都是自己设计的，并且每一步都和单词学习挂钩。

| 部分 | 规则 |
|---|---|
| 一局 | 你和 7 支电脑小队（🐻小熊队、🐰兔兔队、🐬海豚队、🐼熊猫队、🦊狐狸队、🐧企鹅队、🐱小猫队）同场，每队 20 颗爱心，最多 15 回合。每回合和一支小队比赛，其他小队之间也在比；输了扣爱心（1 + 回合÷4 + 对面剩下的只数，最多算 4 只），爱心扣完就出局。最后按名次给 0–3 星。顶部一排头像就是实时排名 |
| 小星灵回合 | 第 1、4、8、12 回合打 🌟 小星灵：赢了掉 2 个道具（第 1 回合 1 个），输了也给 1 个，而且不扣爱心 |
| 词宝 | 词性决定类型：名词 🐻 盾盾宝（能量多）、动词 🐰 冲冲宝（力气大）、形容词 🦄 星光宝（顺带砸到旁边）、副词 🐦 闪闪宝（最快，专找后排） |
| 词卡档次 | A2 是 1🪙 卡，B1 2🪙，B2 3🪙，9 个字母以上的长词再贵 1 档（最高 4🪙）。档次越高越强（×1 / 1.25 / 1.5 / 1.8） |
| 等级 | 从 Lv3 开始，等级 = 能上场的只数（最多 9）。每回合 +2 经验，也可以花 4🪙 买 4 经验。等级越高，小屋里出现高档词卡的概率越大（Lv3：1🪙卡 80%、2🪙卡 20% … Lv9：1–4🪙 卡 15/25/35/25%），概率写在小屋下面 |
| 请词宝 = 答题 | 第 1 次请：选中文意思；第 2 次：例句选词填空（升 2 星）；第 3 次：字母块拼写（升 3 星，戴皇冠 👑）。答错不扣词币，这张卡本回合休息；同一回合错满 3 题，词宝老师 🦉 把这 3 个词再讲一遍 |
| 技能 | 每只词宝出手 +10、被打 +6 技能条，满 100 放技能：🫧 护盾泡泡（给自己和旁边队友加护盾）、🦘 大跳跃（2.5 倍一击）、🌠 星光雨（砸中目标和周围）、⚡ 闪闪连击（连扔 3 个不同对手） |
| 组合 | 每个组合分档，高档会改变比赛打法：**同班同学**（同主题 2/4/6）护盾 30/45/60%，第 2 档起护盾被打破时💥泡泡爆开砸最近的对手，第 3 档爆完再长出一半护盾；**一家人**（同词根 2/3/4）力气 +20/35/50%，而且家里谁打一下全家力气再涨（越打越有劲💪）；**对对碰**（反义词挨着）第 3 秒放🎆烟花，加强后每 6 秒再放；**好朋友**（近义词挨着）出手快 30%，一只去休息时另一只🔁接力（力气 +50%、技能条加满）；**同类队**（同词性 2/4/6，副词 2/3/4）：盾盾宝能量更多、第 2 档🔁弹回去伤害；冲冲宝力气更大、第 2 档第一下🚀跳到后排 2 倍；星光宝砸得更开、第 2 档让对手😵晃眼变慢；闪闪宝更快、第 2 档有机会💨闪开。同班同学/一家人答对关系题再升一档 |
| 组合看得见 | 组合标签上有 ●●○ 档位进度，差 1 只升档会提示；点标签弹出每一档的效果和还差几只。比赛里每次组合触发都会在词宝头上冒字、闪光、有提示音。赛后“本场组合表现”用条形图列出每个组合挡住或打出了多少 |
| 关系题 | 每个组合第一次出现时出题：同班同学/一家人/对对碰/好朋友问“这两个词是什么关系”，答对本局加强一档；同类队问“这几个词都是什么词性”。答对都送 1 词币 |
| 道具 | 🎒能量书包（能量 +30%）、🖍️彩虹蜡笔（力气 +25%）、👟飞飞跑鞋（快 25%）、🫧泡泡帽（开场护盾 30%）、📘小字典（开场技能条半满）、🍀幸运草（25% 机会双倍）。点道具再点词宝装上，每只最多 2 个；送回小屋时道具退回 |
| 词币 | 每回合基础 +5；利息每存 10 个 +1（最多 +3）；赢一场 +1；连胜或连败 2–3 场 +1、4 场以上 +2；连对 3 题 +1；换一批 1🪙 |
| 变变贴纸 | 赢小队有一半机会得到前后缀贴纸（un- -er -or -ful -ly -y -ness），贴到对应词宝上并选对拼法，它就变成新词 |
| 难度照顾 | 对手只数最多比你多 1 只；你刚输过，下一场对手只数和星级低一点 |
| 复习 | 小屋抽卡时更常出现到期该复习的词和答错过的词；首页有错词本和皇冠词 |

## 词池

`node tools/build-autochess.js` 生成词池，写进 `index.html` 的 `/*DATA*/` 区：

- 单词、级别、中文、例句、主题来自 `words/*.txt`（主题 = 单词星系的 18 个星系，去掉虚词“小词大用”）。
- 词性来自 `autochess/pos.txt`（WordNet 词频加中文释义自动推断，可以手改），脚本里还有一张手工词性表优先。
- 反义词来自词库的 `ant:` 关系、`words/links.txt` 和 un- 前缀；词根家族按后缀/前缀自动找（help → helper / helpful），加上词库的 `root:` 关系，脚本里有一张“拼写碰巧像但无关”的排除表。

目前 3311 词（A2 1055、B1 966、B2 1290）、193 个词根家族、574 个词有反义词、708 个词有近义词（只配同词性的近义词，来自词库 `syn:` 关系和 `words/links.txt` 的 `## syn`）。中文释义含咒、魔、鬼、怪、杀、死、血等字的词，以及打仗、犯罪、烟酒类的词不进词池。首页可选词库：KET / KET+PET（默认）/ KET+PET+FCE；每局随机用 5 个主题。

## 自测

用 Playwright 脚本自动玩完整局（会挑组合卡、换位置、装道具、升级），检查无报错、15 回合内能分出名次、其他小队会陆续出局。

## 试玩时看两件事

孩子会不会为了凑组合主动去请某个词、主动挪位置让反义词挨着；玩完能不能说出几组“一家人”和“对对碰”。
